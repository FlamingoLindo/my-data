# My Data

> Warning: This project is still under construction and may change significantly as development continues.

My Data is a personal information management app built with SvelteKit, TypeScript, and Tailwind CSS. It provides a simple dashboard for organizing and editing structured records such as general profile information, addresses, contact details, work data, health information, documents, and banking details. The website is also designed to work well on phones and smaller screens.

## Overview

The project is designed as a route-based form system where each category of personal data has its own page and section form. Users can navigate from a central menu to manage different record types in a consistent interface.

## Features

- Personal dashboard and login screen
- Mobile-friendly layout that works on phones
- Central menu for grouped records
- Individual pages for:
  - General information
  - Address
  - Work
  - Military
  - Social media
  - Driver details
  - Passport details
  - Health info
  - Academics
  - Emails
  - Bank info
  - Phone numbers
- Reusable form and UI components
- Modern styling with Svelte + Tailwind + shadcn-svelte patterns
- TypeScript interfaces for structured data models

## Tech Stack

- SvelteKit
- Svelte
- TypeScript
- Vite
- Tailwind CSS
- shadcn-svelte
- @iconify/svelte and related UI libraries
